# Prompt Analyzer 使用指南

> 面向产品经理、运营人员及管理层的平台使用手册
> 最后更新：2026-04-12

---

## 这个平台能帮你做什么？

Prompt Analyzer 帮助你**理解用户是如何使用 Tripo 3D 生成服务的**。通过分析用户输入的 Prompt（文本指令），你可以回答以下问题：

- 用户主要在生成什么类型的 3D 模型？（角色、建筑、道具、车辆……）
- 用户来自哪些语言群体？中英文用户的使用差异是什么？
- 最近有哪些热门趋势？什么品类在增长？
- 用户 Prompt 的质量如何？描述是否够清晰具体？
- 哪些 Prompt 效果最好（点赞最多）？有什么规律可以复用？
- 平台的核心问题是什么？运营应该从哪里入手？

---

## 快速上手（3 步开始）

> 首次使用前，请确保开发团队已完成平台部署。部署完成后，你只需一个浏览器。

### 第 1 步：打开平台

在浏览器中访问平台地址（通常为 `http://localhost:3000`，具体地址请咨询开发团队）。

左侧导航栏包含 11 个分析模块：

```
总览 / 分类标签 / 主题聚类 / 趋势分析 / 语言与质量 /
意图分析 / 数据浏览 / 创作路径 / 效果分析 / 主题分析 / 爆款模板
```

### 第 2 步：同步数据

点击右上角的 **「同步数据」** 按钮，系统会从数据仓库中拉取最新的 Prompt 数据。

- 首次同步可能需要 1-2 分钟，请耐心等待
- 同步后可直接浏览各页面的基础图表

### 第 3 步：运行分析

点击右上角的 **「运行分析」** 按钮，系统会自动执行全套分析流程（22 步）。

页面顶部会显示进度条和当前步骤名称。整个过程大约需要 **5-15 分钟**（取决于数据量）。分析完成后，所有图表会自动更新为最新结果。

> **提示**：平台有数据缓存机制，切换页面时不会重复加载，速度很快。

## 各页面功能详解

### 1. 总览（Dashboard）

**适合场景：** 快速了解整体情况，日常巡检，汇报准备

打开平台首先看到总览页，包含以下模块：

| 模块 | 你能看到什么 |
|------|-------------|
| KPI 卡片 | 总 Prompt 数、独立用户数、平均 Prompt 长度、热门类别 |
| **平台总览洞察** | 系统自动生成的 4 模块业务分析（见下文） |
| 类别分布 | 柱图展示各类 3D 模型的数量（前 10 名） |
| 风格分布 | 饼图展示用户偏好的视觉风格 |
| 每日 Prompt 量 | 折线图展示每天的 Prompt 提交量趋势 |
| 语言分布 | 用户使用的语言比例 |

#### 平台总览洞察卡片（重点）

这是一个蓝色背景的业务分析卡片，包含 4 个模块，由系统基于实时数据自动生成：

1. **核心业务现状** — 平台规模、人均创作量、核心需求集中度、主流风格、国际化现状
2. **关键数据洞察** — 5 条带数据支撑的业务解读（活跃度、需求结构、风格偏好、Prompt 质量、语言国际化）
3. **问题诊断与风险提示** — 基于数据客观指出当前问题（如需求集中度高、风格单一、留存偏低）
4. **可落地优化建议** — 每条建议对应具体问题，点击其中的**蓝色类别/风格名称**可跳转到对应详情页

**使用建议：**
- 洞察卡片的文字可直接引用到周报/月报中
- 点击洞察中的蓝色关键词，快速导航到对应分析页面
- 卡片基于已加载数据实时生成，运行分析后刷新页面可更新

### 2. 分类标签

**适合场景：** 了解用户需求分布，指导产品规划

深入查看用户 Prompt 在各个维度的分布情况：

- **类别分布** — 用户最想生成什么？（角色设计 vs 建筑场景 vs 道具物品……）
- **风格分布** — 用户偏好什么风格？（写实 vs 卡通 vs 赛博朋克……）
- **用途分布** — 用户的使用场景是什么？（游戏 vs 影视 vs 电商……）
- **颜色分布** — 用户偏好的色彩倾向

**使用建议：**
- 关注头部类别的占比变化，判断市场需求方向
- 风格分布结合类别分布一起看，找出主流创作模式

---

### 3. 主题聚类

**适合场景：** 发现细分主题和用户群体

系统自动将相似的 Prompt 聚成若干主题群。你会看到一个散点图，每个点代表一条 Prompt，颜色相同的点属于同一主题。

- 每个主题会显示其核心关键词
- 聚类越大，代表该主题的用户越多

**使用建议：**
- 寻找你没有预料到的主题——这可能是未被满足的用户需求
- 关注较大的聚类——代表平台的主流使用场景

---

### 4. 趋势分析

**适合场景：** 捕捉热点、发现增长机会

| 模块 | 说明 |
|------|------|
| 热词趋势 | 近期热度上升最快的关键词 |
| 每日趋势 | 按日查看 Prompt 提交量变化 |
| 类别趋势 | 各品类的每日趋势折线图 |
| 词云 | 高频关键词的可视化，直观展示热门主题 |

**使用建议：**
- 每周关注热词趋势，及时捕捉用户兴趣变化
- 词云适合放在汇报 PPT 中，视觉效果好

---

### 5. 语言与质量

**适合场景：** 了解用户地域分布和 Prompt 质量

#### 语言分布
- 饼图/柱图展示中文、英文及其他语言的 Prompt 占比
- 帮助判断国际化优先级

#### 文本统计
- Prompt 平均长度（字符数）、中位数、P95 分位
- 词汇多样性指标
- 直方图展示长度分布

#### 质量评分雷达图

系统从 4 个维度为 Prompt 打分（1-5 分），综合所有用户数据展示平台整体质量水平：

| 维度 | 含义 | 为什么重要 |
|------|------|-----------|
| 具体性 | Prompt 描述是否具体详细 | 越具体，生成效果越好 |
| 清晰度 | 表达是否清晰、有分类标签 | 影响模型理解准确度 |
| 创造力 | 是否有独特的风格偏好 | 反映用户创作多样性 |
| 技术细节 | 是否包含颜色/风格/关键词等标签 | 反映用户的专业程度 |

> **说明**：质量评分在 AI 分析可用时由 Claude 评估；AI 不可用时自动切换为基于本地数据的代理指标（效果相近，无需手动干预）。

**使用建议：**
- 如果整体质量偏低，可考虑增加 Prompt 引导/模板功能
- 具体性偏低说明用户描述过简，建议增加 Prompt 填写引导

### 6. 意图分析

**适合场景：** 精准理解用户目的

AI 将每条 Prompt 分类为以下 10 种意图之一：

| 意图 | 示例 |
|------|------|
| 角色设计 | "一个穿盔甲的女战士" |
| 生物动物 | "一只冰龙" |
| 交通工具 | "未来风格的摩托车" |
| 建筑场景 | "日式庭院" |
| 道具物品 | "中世纪宝箱" |
| 武器装甲 | "双刃光剑" |
| 家具装饰 | "北欧风格书架" |
| 食物自然 | "樱花树" |
| 抽象标志 | "公司 3D Logo" |
| 其他 | — |

页面还包含：
- **意图 × 对象类别交叉分析**：热力图展示不同意图与类别的组合频次，点击可查看示例
- **意图效果对比**：各意图的平均点赞数，直观判断哪类意图效果最好

**使用建议：**
- 观察各意图的占比，了解用户核心诉求
- 结合运营活动，看特定意图是否有明显波动
- 点击热力图中的意图方块，可查看该组合的真实 Prompt 示例

### 7. 数据浏览

**适合场景：** 查看原始数据、搜索特定 Prompt

这是一个功能完整的数据表格，支持：

- **搜索** — 输入关键词搜索 Prompt 内容
- **筛选** — 按类别、风格、语言过滤
- **翻页** — 浏览大量数据
- **导出** — 下载 CSV 文件，可在 Excel 中进一步分析

**使用建议：**
- 当你在其他页面发现有趣的模式时，来这里查看具体的 Prompt 原文
- 导出数据后可以用 Excel 做自定义的透视表分析

---

### 8. 创作路径

**适合场景：** 了解用户的创作行为链路

桑基图展示用户从一种类别迁移到另一种类别的路径，揭示用户创作习惯：

- 哪些类别是用户的「入门选择」？
- 用户创作一段时间后会转向哪些方向？
- 类别间的转化关系是什么？

**使用建议：**
- 找出高频迁移路径，在产品中提前做好引导推荐
- 关注从主流类别流出的去向，判断用户拓展需求

---

### 9. 效果分析

**适合场景：** 找出爆款规律，指导内容运营

这是平台最核心的运营分析模块，包含：

| 模块 | 说明 |
|------|------|
| 爆款 Prompt 排行 | 按点赞数/收藏数排列的高效果 Prompt 列表 |
| Prompt 特征与点赞的相关性 | 哪些 Prompt 特征（长度、是否有风格词等）与高点赞强相关 |
| 各类别平均点赞 | 哪个类别的内容效果最好 |
| 特征间共线性热力图 | 各特征之间的相关性，附业务解读说明 |

**爆款 Prompt 详情**：点击爆款列表中的任意一行，可查看该 Prompt 的完整内容。

**使用建议：**
- 效果分析是核心运营参考，建议重点关注「特征与点赞相关性」——哪些写法真正带来高互动
- 爆款 Prompt 列表可作为模板库的参考来源
- 点击爆款查看原文，学习高效 Prompt 的写作模式

---

### 10. 主题分析

**适合场景：** 深度理解细分主题的效果差异

基于 BERTopic 算法的高级主题分析，包含：

- **主题矩形树图** — 各主题的规模大小，颜色深浅代表数量
- **主题数据洞察** — 自动生成的分析结论（哪个主题效果最好、倍数是多少）
- **主题 - 效果散点图** — 规模 vs 平均点赞的气泡图，找出「小而美」的高效率主题
- **主题平均点赞排行** — 各主题效果对比柱图

**使用建议：**
- 散点图右上角（规模大且点赞高）是理想的运营聚焦区域
- 规模大但点赞低的主题，说明用户需求大但满意度低，值得重点优化

---

### 11. 爆款模板

**适合场景：** 直接获取可复用的高效 Prompt 模板

系统自动从高点赞 Prompt 中提炼通用模板，每个模板包含：
- 模板结构（可填写的通用框架）
- 所属类别和风格
- 参考效果数据
- 一键复制按钮

**使用建议：**
- 将模板库直接提供给内容创作团队或 C 端用户
- 定期运行分析后，模板库会更新为最新的爆款规律

## 日常使用建议

### 每日快速巡检（5 分钟）

1. 打开 **总览**，浏览 KPI 卡片和业务洞察结论
2. 扫一眼 **趋势分析** 页面的热词，看有无异常波动

### 每周深度分析（30 分钟）

1. 点击 **「同步数据」** 获取最新数据
2. 点击 **「运行分析」** 执行完整分析流程
3. 重点查看 **效果分析** 和 **主题分析**，记录关键发现
4. 从 **数据浏览** 导出数据留存备份

### 汇报准备

以下内容可直接用于汇报材料：

| 汇报内容 | 数据来源 |
|----------|---------|
| 用户量/Prompt 量概况 | 总览 KPI 卡片 |
| 核心现状与业务建议 | 总览「平台总览洞察」卡片（可直接引用） |
| 用户需求分布 | 分类标签页类别分布图 |
| 用户画像（语言/地域） | 语言与质量页语言分布 |
| 近期热点趋势 | 趋势分析热词 + 词云 |
| 爆款内容规律 | 效果分析 + 爆款模板 |
| Prompt 质量现状 | 语言与质量页质量雷达图 |

## 名词解释

| 术语 | 含义 |
|------|------|
| Prompt | 用户输入的文本指令，描述想要生成的 3D 模型 |
| Pipeline（分析管线） | 系统自动执行的 22 步分析流程 |
| 同步数据 | 从数据仓库拉取最新 Prompt 数据到本地 |
| 意图分类 | AI 判断用户想生成什么类型的 3D 模型 |
| 质量评分 | 从多个维度对 Prompt 的描述质量打分（1-5 分） |
| 效果指标 | 点赞数（like_count）、收藏数（collect_count）等用户互动数据 |
| 爆款 Prompt | 获得高点赞/收藏的优质 Prompt |
| BERTopic | 一种高级主题建模算法，比 LDA 更准确 |
| Spearman 相关性 | 衡量两个变量之间关联强度的统计指标（-1 到 1） |
| KPI | 关键绩效指标，用数字概括平台核心数据 |
| 词云 | 将高频词按出现频率大小排列的可视化图 |

## 常见问题

**Q: 总览页没有业务洞察卡片？**
A: 洞察卡片需要 KPI 数据加载完成才会显示（需先完成同步数据）。如果数据已同步但仍不显示，刷新页面即可。

**Q: 语言与质量页质量雷达图是空的？**
A: 正常情况下雷达图会显示本地计算的代理指标。若仍为空，可能是数据尚未同步，请先点击「同步数据」。

**Q: 效果分析里点击爆款 Prompt 后显示「未找到 Prompt 数据」？**
A: 目前详情页直接读取效果分析缓存中的数据，若数据已清除可重新点击「运行分析」更新缓存后再试。

**Q: 页面上没有数据/图表为空？**
A: 需要先点击「同步数据」同步数据，部分分析（意图/质量/主题等）还需点击「运行分析」。首次使用两步都要执行。

**Q: 分析需要多长时间？**
A: 通常 5-15 分钟，取决于数据量。顶部进度条会显示当前步骤和进度，完成后图表自动更新。

**Q: 数据多久更新一次？**
A: 按需更新。随时可点击「同步数据」拉取最新数据，之后点击「运行分析」重新计算所有指标。

**Q: 可以导出数据吗？**
A: 可以。在「数据浏览」页面点击导出按钮，下载 CSV 文件用 Excel 打开即可。

**Q: 洞察卡片的内容可以直接引用吗？**
A: 可以。卡片内容基于真实数据实时生成，数字准确，可直接用于报告材料。建议阅读后适当编辑，加入自己的判断和背景信息。

**Q: 平台打不开怎么办？**
A: 请联系开发团队确认后端（5000 端口）和前端（3000 端口）服务是否正常运行。
