# Prompt Analyzer 使用指南

> 面向产品经理、运营人员及管理层的平台使用手册

---

## 这个平台能帮你做什么？

Prompt Analyzer 帮助你**理解用户是如何使用 Tripo 3D 生成服务的**。通过分析用户输入的 Prompt（文本指令），你可以回答以下问题：

- 用户主要在生成什么类型的 3D 模型？（角色、建筑、道具、车辆……）
- 用户来自哪些语言群体？中英文用户的使用差异是什么？
- 最近有哪些热门趋势？什么品类在增长？
- 用户 Prompt 的质量如何？描述是否够清晰具体？
- 有哪些值得关注的使用模式和洞察？

---

## 快速上手（3 步开始）

> 首次使用前，请确保开发团队已完成平台部署。部署完成后，你只需一个浏览器。

### 第 1 步：打开平台

在浏览器中访问平台地址（通常为 `http://localhost:3000`，具体地址请咨询开发团队）。

你会看到左侧导航栏和主内容区：

```
┌──────────┬───────────────────────────────────────┐
│          │                                       │
│ Dashboard│         主 内 容 区                    │
│ 分类分析  │                                       │
│ 主题聚类  │     （图表、数据、洞察）                 │
│ 意图分析  │                                       │
│ 语言分析  │                                       │
│ 趋势分析  │                                       │
│ 数据浏览  │                                       │
│          │                                       │
└──────────┴───────────────────────────────────────┘
```

### 第 2 步：同步数据

点击页面上的 **"Sync Data"（同步数据）** 按钮，系统会从数据仓库中拉取最新的 Prompt 数据。

- 首次同步可能需要 1-2 分钟，请耐心等待
- 数据会缓存 24 小时，之后可再次同步获取最新数据

### 第 3 步：运行分析

点击 **"Run Pipeline"（运行分析）** 按钮，系统会自动执行全套分析流程。

你会看到一个进度条，从 0% 到 100%。整个过程大约需要 **3-10 分钟**（取决于数据量）。分析完成后，所有页面的图表和数据会自动更新。

## 各页面功能详解

### 1. Dashboard（总览仪表盘）

**适合场景：** 快速了解整体情况，汇报用

这是你的"首页"，一眼看清全局：

| 模块 | 你能看到什么 |
|------|-------------|
| KPI 卡片 | 总 Prompt 数、类别数、语言数等关键指标 |
| 类别分布 | 饼图/柱图展示各类 3D 模型的占比（角色、建筑、车辆等） |
| 风格分布 | 用户偏好的视觉风格（写实、卡通、低多边形等） |
| 每日数据量 | 折线图展示每天的 Prompt 提交量趋势 |
| 语言分布 | 用户使用的语言比例 |
| AI 洞察 | 系统自动生成的数据分析总结（中英双语） |

**使用建议：**
- 定期截图 KPI 卡片用于周报/月报
- AI 洞察部分可直接引用到汇报材料中

---

### 2. Categories（分类分析）

**适合场景：** 了解用户需求分布，指导产品规划

深入查看用户 Prompt 在各个维度的分布情况：

- **类别分布** -- 用户最想生成什么？（角色设计 vs 建筑场景 vs 道具物品……）
- **风格分布** -- 用户偏好什么风格？（写实 vs 卡通 vs 赛博朋克……）
- **用途分布** -- 用户的使用场景是什么？（游戏 vs 影视 vs 电商……）
- **颜色分布** -- 用户偏好的色彩倾向

**使用建议：**
- 关注头部类别的占比变化，判断市场需求方向
- 对比不同时期的分布，发现增长/衰退品类

---

### 3. Topics（主题聚类）

**适合场景：** 发现细分主题和用户群体

系统自动将相似的 Prompt 聚成若干主题群。你会看到一个散点图，每个点代表一条 Prompt，颜色相同的点属于同一主题。

- 每个主题会显示其核心关键词
- 点击某个主题可以查看该群组中的典型 Prompt

**使用建议：**
- 寻找你没有预料到的主题——这可能是未被满足的用户需求
- 关注较大的聚类——代表主流使用场景

---

### 4. Intents（意图分析）

**适合场景：** 精准理解用户目的

AI 将每条 Prompt 分类为以下 10 种意图之一：

| 意图 | 说明 | 示例 |
|------|------|------|
| 角色设计 | 人物、角色模型 | "一个穿盔甲的女战士" |
| 生物动物 | 动物、奇幻生物 | "一只冰龙" |
| 交通工具 | 车辆、飞行器 | "未来风格的摩托车" |
| 建筑场景 | 建筑、环境 | "日式庭院" |
| 道具物品 | 日常物品、游戏道具 | "中世纪宝箱" |
| 武器装甲 | 武器、防具 | "双刃光剑" |
| 家具装饰 | 家具、室内装饰 | "北欧风格书架" |
| 食物自然 | 食物、植物、自然物 | "樱花树" |
| 抽象标志 | Logo、抽象图形 | "公司 3D Logo" |
| 其他 | 未归类 | - |

每个意图类别下都会展示示例 Prompt，帮助你直观理解。

**使用建议：**
- 观察各意图的占比，了解用户核心诉求
- 结合运营活动，看特定意图是否有明显波动

---

### 5. Language（语言分析）

**适合场景：** 了解用户地域分布和 Prompt 质量

#### 语言分布
- 饼图展示中文、英文及其他语言的 Prompt 占比
- 帮助判断国际化优先级

#### 文本统计
- Prompt 平均长度（字符数、词数）
- 词汇多样性指标
- 直方图展示长度分布

#### 质量评分
AI 从 4 个维度为 Prompt 打分（1-5 分）：

| 维度 | 含义 | 为什么重要 |
|------|------|-----------|
| 具体性 | Prompt 描述是否具体详细 | 越具体，生成效果越好 |
| 清晰度 | 表达是否清晰无歧义 | 影响模型理解准确度 |
| 创造力 | 是否有创意和独特性 | 反映用户群体的创作水平 |
| 技术细节 | 是否包含技术参数描述 | 反映用户的专业程度 |

**使用建议：**
- 如果整体质量偏低，可考虑增加 Prompt 引导/模板功能
- 对比中英文 Prompt 的质量差异，针对性优化引导策略

---

### 6. Trends（趋势分析）

**适合场景：** 捕捉热点、发现增长机会

| 模块 | 说明 |
|------|------|
| 热词趋势 | 近期热度上升最快的关键词，带有"动量"指标 |
| 每日趋势 | 按日查看 Prompt 提交量变化 |
| 类别趋势 | 各品类的每日趋势折线图，发现增长/下降品类 |
| 词云 | 高频关键词的可视化词云，直观展示热门主题 |

**使用建议：**
- 每周关注热词趋势，及时捕捉用户兴趣变化
- 词云适合放在汇报 PPT 中，视觉效果好
- 类别趋势结合运营活动看效果

---

### 7. Explorer（数据浏览器）

**适合场景：** 查看原始数据、搜索特定 Prompt

这是一个功能完整的数据表格，支持：

- **搜索** -- 输入关键词搜索 Prompt 内容
- **筛选** -- 按类别、风格、语言过滤
- **翻页** -- 浏览大量数据
- **导出** -- 点击导出按钮下载 CSV 文件，可在 Excel 中进一步分析

**使用建议：**
- 当你在其他页面发现有趣的模式时，来这里查看具体的 Prompt 原文
- 导出数据后可以用 Excel 做自定义的透视表分析

## 日常使用建议

### 每日快速查看（5 分钟）

1. 打开 **Dashboard**，浏览 KPI 和每日数据量趋势
2. 扫一眼 **Trends** 页面的热词，看有无异常波动

### 每周深度分析（30 分钟）

1. 点击 **Sync Data** 同步最新数据
2. 点击 **Run Pipeline** 运行完整分析
3. 逐页查看各分析页面，记录关键发现
4. 从 **Explorer** 导出数据备份

### 汇报准备

以下内容可直接用于汇报材料：

| 汇报内容 | 数据来源 |
|----------|---------|
| 用户量/Prompt 量概况 | Dashboard KPI 卡片 |
| 用户需求分布 | Categories 类别分布图 |
| 用户画像（语言/地域） | Language 语言分布 |
| 近期热点趋势 | Trends 热词 + 词云 |
| Prompt 质量现状 | Language 质量评分 |
| AI 自动分析总结 | Dashboard AI 洞察（中英双语，可直接引用） |

## 名词解释

| 术语 | 含义 |
|------|------|
| Prompt | 用户输入的文本指令，描述想要生成的 3D 模型 |
| Pipeline（分析管线） | 系统自动执行的一系列分析步骤 |
| Sync（同步） | 从数据仓库拉取最新数据到本地 |
| TF-IDF | 一种统计方法，用于找出文本中最有区分度的关键词 |
| LDA 主题模型 | 一种自动发现文本主题的算法 |
| 意图分类 | AI 判断用户想生成什么类型的 3D 模型 |
| 质量评分 | AI 从多个维度对 Prompt 的描述质量打分 |
| 词云 | 将高频词按出现频率大小排列的可视化图 |
| KPI | 关键绩效指标，用数字概括平台核心数据 |

## 常见问题

**Q: 页面上没有数据/图表为空？**
A: 需要先点击 "Sync Data" 同步数据，再点击 "Run Pipeline" 运行分析。首次使用两步都要执行。

**Q: 分析需要多长时间？**
A: 通常 3-10 分钟，取决于数据量。页面会显示进度条，完成后图表自动更新。

**Q: 数据多久更新一次？**
A: 数据缓存 24 小时。你随时可以点击 "Sync Data" 手动拉取最新数据并重新运行分析。

**Q: 可以导出数据吗？**
A: 可以。在 "Explorer（数据浏览器）" 页面点击导出按钮，下载 CSV 文件用 Excel 打开即可。

**Q: AI 洞察/总结内容可以直接引用吗？**
A: 可以。AI 总结提供中英双语版本，建议阅读后适当编辑再用于正式材料。

**Q: 平台打不开怎么办？**
A: 请联系开发团队确认后端和前端服务是否正常运行。
